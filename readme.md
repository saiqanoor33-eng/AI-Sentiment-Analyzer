
# AI Sentiment Analyzer

## Overview
AI Sentiment Analyzer is a simple NLP application that analyzes English text and classifies its sentiment as Positive, Negative, or Neutral.

## Features
- User text input
- Automated sentiment analysis
- Sentiment score and detailed polarity scores
- Empty input validation
- Interactive Streamlit interface

## Technologies
- Python
- Streamlit
- VADER Sentiment Analysis
- Natural Language Processing (NLP)

## Run Locally
1. Install Python.
2. Install dependencies using:
   pip install -r requirements.txt
3. Run the application:
   streamlit run app.py

## Limitations
The model works best with English text. Sarcasm and context may affect the results.
